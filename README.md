# Nyx Client

Instalator launchera Nyx Client dla Minecrafta 1.21.11 (Java) na Windows 10 i 11. Robi go Nyx Studio.

Pobierz najnowszą wersję z zakładki **Releases** po prawej, plik `NyxClient-Setup-<wersja>.exe`.

## Jak zainstalować

1. Musisz mieć kupionego Minecrafta i oficjalny launcher z minecraft.net.
2. Uruchom instalator. Jeśli Windows pokaże „System Windows ochronił ten komputer”, kliknij „Więcej informacji”, potem „Uruchom mimo to”. Antywirus może skanować plik około minuty, bo to nowy program bez płatnego podpisu.
3. W launcherze Nyx kliknij „Zainstaluj”. Pobierze Fabric i mody.
4. Kliknij „Graj”. Otworzy się oficjalny launcher z profilem „Nyx Client”, tam grasz na swoim koncie Microsoft.
5. W grze menu modów otwierasz prawym Shiftem.
