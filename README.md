# NyxCode Client

Instalator launchera NyxCode Client dla Minecrafta 1.21.11 (Java) na Windows 10 i 11. Robi go NyxCode.

Pobierz najnowszą wersję z zakładki **Releases** po prawej, plik `NyxCode-Setup-<wersja>.exe`.

## Instalator (kupiony Minecraft)

1. Musisz mieć kupionego Minecrafta i oficjalny launcher z minecraft.net.
2. Uruchom instalator. Jeśli Windows pokaże „System Windows ochronił ten komputer”, kliknij „Więcej informacji”, potem „Uruchom mimo to”. Antywirus może skanować plik około minuty, bo to nowy program bez płatnego podpisu.
3. W launcherze NyxCode kliknij „Zainstaluj”. Pobierze Fabric i mody.
4. Kliknij „Graj”. Otworzy się oficjalny launcher z profilem „NyxCode Client”, tam grasz na swoim koncie Microsoft.
5. W grze menu modów otwierasz prawym Shiftem.

## Wersja sam mod (non premium)

Dla kont non premium (np. TLauncher) i innych launcherów z Fabric (Prism, MultiMC, Modrinth App).

1. Pobierz z **Releases** plik `NyxCode-Mod-<wersja>.zip`.
2. W swoim launcherze wybierz wersję Fabric 1.21.11 (Fabric Loader 0.19 albo nowszy) i odpal ją raz.
3. Wrzuć oba pliki `.jar` z paczki (NyxCode Client i Fabric API) do folderu `mods` tej wersji.
4. W grze menu modów otwierasz prawym Shiftem. Na FPS i shadery możesz dorzucić Sodium, Lithium i Iris z modrinth.com.

Na koncie non premium działa wersja darmowa. Premium+ wymaga kupionego Minecrafta, bo licencja przypina się do konta Microsoft.
